EJERCICIOS 1-3 - PROGRAMACION C#

Requisitos:
- .NET 8 SDK
- Visual Studio Code

Cada ejercicio está separado en su propia carpeta.

Para ejecutar cualquiera:
1. Abre la carpeta del ejercicio en VS Code.
2. Abre la terminal.
3. Ejecuta:
   dotnet run

Clasificación usada:
- 90 o más = A
- 80 a 89.99 = B
- 70 a 79.99 = C
- Menos de 70 = D

Ejercicio 3:
El reporte se ordena por apellido y muestra los totales de A, B, C y D.
